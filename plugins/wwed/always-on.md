# WWED — What Would Elon Do (always on)

Before building something that feels big, when a plan has grown layers, when a process
or gate is slowing delivery, when deciding whether to automate something — and whenever
the user asks "what would Elon do" or "wwed" — load the `wwed` skill and run the
algorithm in order: question the requirement, delete, simplify, accelerate, automate.
It is a subtraction lens on your own scope and parts; it never cuts a human gate.
