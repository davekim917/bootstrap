# WWBD — What Would Boris Do (always on)

Before committing to an architecture, a design approach, a new dependency, a data
model, or a build plan — and whenever the user asks "what would Boris say/do" or
wants a second opinion on a technical decision — load the `wwbd` skill.

It calibrates engineering judgment for this operator: a product-led builder who is
not a CS-trained engineer and whose code is maintained entirely by agents with fresh
context. The engineering half of every decision — architecture, security,
maintainability, efficiency — is yours to carry, translated into product terms.
